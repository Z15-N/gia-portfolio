# Feature Specification: Shareable, stable, judge-ready polish

**Feature Branch**: `001-share-polish` | **Created**: 2026-11-05 | **Status**: Draft

## User scenarios

### 1. Sharing the link (priority P1)
Gia pastes the site URL into LinkedIn, Discord or a message. A preview card appears with his name, a one-line description and a honeycomb image, instead of a blank card or a random crop.
- Given the URL is pasted into LinkedIn or Discord, when the preview loads, then it shows title "Gia Bach Nguyen", the description, and a 1200x630 image.

### 2. Jumping to a section (P1)
A visitor clicks "Projects" in the top bar. The section heading lands fully visible below the sticky header, not hidden under it.
- Given the sticky header is 60px tall, when any nav anchor is followed, then the section's heading sits at least 16px below the header.

### 3. Page loading on a slow connection (P2)
Images in the Projects cards reserve their space before they load, so text does not jump when they arrive.
- Given images are still loading, when the page renders, then each image box already has its final height.

### 4. Safari and bookmarks (P2)
Safari and older browsers that ignore SVG favicons still show a bee icon in the tab and in bookmarks.

### 5. Freshness (P3)
The footer shows the month the site was last updated, set automatically at build time.

## Requirements
- FR-1: `<head>` carries Open Graph and Twitter card tags (title, description, image, url, type) and a `theme-color`.
- FR-2: `assets/og.png` exists, 1200x630, honeycomb + bee + name + tagline, generated by a script in `tools/` so it can be regenerated.
- FR-3: Sections with ids have `scroll-margin-top` equal to the header height plus 16px.
- FR-4: Every `<img>` has `width` and `height` attributes matching the file.
- FR-5: `assets/favicon.png` (64x64) is linked as a fallback after the SVG icon.
- FR-6: `tools/package.sh` writes the build month into the footer.
- Constraints: no new runtime dependencies; generation scripts may use Python via `uv run --with pillow`. Constitution principles I to VI apply.

## Success criteria
- Pasting the live URL into a LinkedIn post shows the card (manual check by Gia after deploy).
- Clicking each nav link leaves the heading visible under the header at 1800px, 1024px and 375px.
- No console errors, no overflow, Buzz test questions still pass.
